# ML Lab Assignments

This repository contains my weekly machine learning lab assignments for the 5th Semester.

## Repository Structure

Each week's lab files are organized into their respective folders:

*   **[Lab 1](./Lab%201/)**: Exercises and solutions for Lab Session 1, including code (Google Colab) and lab description.
*   **[Lab 2](./Lab%202/)**: Exercises and solutions for Lab Session 2, including code, datasets, and generated plots.
*   **[Lab 3](./Lab%203/)**: Exercises and solutions for Lab Session 3, including K-Means clustering files and datasets.
*   **[Lab 4](./Lab%204/)**: Exercises and solutions for Lab Session 4, including K-Means performance comparisons, clustering, and scalability analysis.

## Setup & Running

Each directory typically contains:
*   A PDF of the lab instructions.
*   The raw dataset (`.xlsx` or `.csv`).
*   A Python script (`bl_sc_*.py`) containing the implementation.
*   Output visualizations/plots (`.png`).

To run any script:
1. Navigate to the specific lab directory.
2. Install any required packages (e.g., `numpy`, `pandas`, `matplotlib`, `scikit-learn`).
3. Run the Python script:
    ```bash
    python <filename>.py
    ```
